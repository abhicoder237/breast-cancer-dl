# Breast Cancer Classification using Deep Learning

## Project Overview
End-to-end Deep Learning project to classify breast cancer
tumors as Malignant or Benign using Neural Networks.

## Tech Stack
- Python 3.9+
- TensorFlow/Keras
- Flask API
- HTML/CSS/JS Frontend

## Setup
```bash
pip install -r requirements.txt
```
